# 點陣符號與像素表情

在既有文字符號庫補入適合 5×5、3×5 的花朵、星光、天氣、音符、紙牌與方向符號。沿用分組、游標插入與預覽後套用。新字形為自行繪製的低解析近似，不複製整頁素材。

像素畫分頁增加「像素表情／上傳圖片」子選單，保留原上傳功能。表情提供貓咪、熊、開心、哭哭、生氣五款；圖卡有真正點陣縮圖、文字名稱與選取狀態。點選只更新預覽，套用才送燈。橫放用 20×5 整面大臉，直放用四個 5×5 小臉，兩種朝向皆保持正面可辨識。

獨立 face 模式與 face id，圖樣由純模組產生。單一資料來源供縮圖、預覽與實燈，沿用 renderer 的方向與 ARGB 編碼。表情選擇會存入狀態與情境收藏，不覆蓋使用者上傳圖片。未知 id 需拒絕；不增加 Matter 傳送頻率，靜態表情每分鐘重送一次以支援燈具恢復。

驗收：新增符號在兩種字型皆存在；五款表情在四方向產生合法100像素、400bytes且不空白，各款可區分；收藏保留表情 id、未夾帶通知排程；手機選單與圖卡點選、預覽不改燈、套用後主機收到裝置回應；原圖片預覽保留。部署前備份修改檔，文件補齊操作，fetch與rebase後推送並核對遠端SHA。

同輪修正：呼吸與閃亮保留時鐘小時／分鐘雙色；橫放靜止及閃爍文字依點亮範圍置中；橫放氣溫使用窄字緊密排列並居中。新增回歸檢查涵蓋兩種字型與四方向。快速切換預覽時僅顯示最後一次請求，避免較舊回應蓋住新選擇。
