# 收藏、選項分組與文字輸入

收藏設於內容頁頂端，最多 12 組；從預覽命名保存，不送燈。點收藏才套用，管理區收合並支援改名、刪除。主機 JSON 原子寫入，僅保存顯示設定，不包含通知、排程或倒數；補眠與倒數期間拒絕套用。收藏檔不進 Git。

時鐘配色採精選、單色、雙色、主題；動態顏色採基本、流動、主題。分組只篩選選項。文字快捷區先選符號或表情，再分四個子分類，提供48個符號、50組4字元內表情；符號插入游標位置或取代選取，文字表情整組帶入，所有選項均需兩種字型支援。操作只改預覽，套用後才送燈。

手動套用結束通知插播並略過 60 秒內新通知；相同文字與顏色在 5 分鐘內去重。服務重新啟動會重置暫停與去重。頁面明示插播，避免把 ERROR 文字誤認為控制器錯誤。名稱統一 Yeelight Cube。

驗證包含收藏容量、重複名稱、改名、刪除、重新載入、欄位排除；四方向兩字型的字形覆蓋；實際主機 API 與點選符號後的輸入／預覽狀態。API 成功和裝置回應不等同肉眼確認燈上樣式。

顏色速度採0.10至1.50倍，預設0.35倍；時鐘按經過時間、文字按畫格停留時間推進相位，預覽與實際顯示都套用倍率。保存至狀態和收藏；維持每300毫秒更新，不增加Matter流量。固定色和靜態蜜糖漸層隱藏滑桿。
